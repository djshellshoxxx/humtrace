# SHA-256 module

## Purpose

Hash the exact bytes of an input file (FIPS 180-4 SHA-256) for report integrity, separately from decoded audio. A digest detects equality with a known byte sequence; it does not establish source, time, authorship or custody, and it is not a signature.

## Files and public API

- `include/humtrace/sha256.hpp`, `src/core/sha256.cpp` (C++20 standard library only).
- `Sha256`: incremental hasher with `update(const void*, size_t)`, `update(std::string_view)`, `finalize()` returning `Sha256Digest` (32 bytes), `hex()` (finalize as 64 lowercase hex characters), `bytes_processed()`, and `reset()`. `update` or `finalize` after finalization throws `std::logic_error` until `reset()`.
- `to_hex(const Sha256Digest&)`.
- `sha256_stream(std::istream&, const CancellationToken* = nullptr, const Sha256Progress& = {})` hashes from the current position to end of stream in blocks of `sha256_block_bytes` (1 MiB). It polls the token before each block (throws `OperationCancelled`), calls the progress callback with cumulative bytes after each block, and throws `std::runtime_error` on a read error.
- `sha256_file(path, cancel, progress)` opens the file read-only in binary mode and hashes all bytes. It throws `std::runtime_error` if the file cannot be opened or if its size before hashing, the number of bytes hashed, and its size after hashing disagree (the caller should mark the result invalidated).
- `Sha256Result` holds `digest`, `hex` and `bytes`.

## Contract

Memory use is one 1 MiB buffer per call regardless of file size. The file is never written, truncated or touched beyond reading. Messages never include file contents or the full path.

## Tests

`tests/unit/test_sha256.cpp` checks the NIST vectors (`""`, `"abc"`, the 448-bit two-block message, one million `'a'`), incremental updates with uneven piece sizes and the 55/56/64-byte padding boundaries, finalize/reset rules, stream progress reporting per block, cancellation between blocks, and that `sha256_file` leaves the file's size and modification time unchanged.

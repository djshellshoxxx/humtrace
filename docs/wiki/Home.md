# HumTrace Wiki

HumTrace (Circuit Drift Labs) is an offline C++ prototype for audio interference analysis. It reads WAV files, computes a
per-frame spectrum, reports nominal 50/60 Hz harmonic measurements and exports JSON. It is a prototype, not a beta release,
and it has no GUI or plugin yet.
